## Version 1.14.0

### Added
- Added a Createrington Currency advancement tab with eleven advancements covering getting bills and a Bank Card, depositing, withdrawing, paying at a terminal, setting a price, making a first sale, hitting the daily mob-drop limit, and carrying $10,000 in bills

### Changed
- Votes now appear as a compact animated strip at the top of the screen instead of chat messages. Vote with Y and N, hide the strip with H, and see the result as a PASSED or FAILED strip when the vote ends
- Ops in admin mode can now start a solo test vote that has no cooldown and does not auto-count the starter as yes
- Updated Create support to 6.0.10 (requires NeoForge 21.1.249 or newer)
- Updated the ApricityUI requirement to 1.2.5.1

### Fixed
- Fixed the ATM screen sitting in the top-left corner of windows that are not 16:10
- Fixed ATM text flashing in a different font for a frame every time a value changed
- Fixed Ctrl+A and dragging highlighting the labels on the ATM screen

### Removed
- Removed the lottery feature, including the /lottery and /join commands

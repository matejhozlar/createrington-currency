## Version 1.3.0

- Added 8 new decorative ATM blocks: Blue, Green, Purple, Black, Brass, Andesite, Red, Pink
- Decorative ATMs are two blocks tall with custom 3D models and animated pulsing logo on screen
- All decorative ATMs function as full ATMs (open the ATM menu on right-click)
- Upper half emits light level 8 (screen glow)
- Crafting recipes for all variants using color-specific materials
- Brass and Andesite recipes require Create mod (conditional loading)
- Requires iron pickaxe or better to mine
- Removed Single Denomination withdraw option (redundant with Choose Bills)
- Fixed History view back button not working with D key
- Redesigned circuit board and keypad item textures (16x16 pixel art)
